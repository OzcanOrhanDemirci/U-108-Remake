# Typefaces

The six typefaces bundled with the game, who made them and the terms they are used under. The
licence and copyright notices below were read from each font file's own `name` table.

| File | Typeface | Author | Licence | Used for |
| --- | --- | --- | --- | --- |
| `Fraunces.ttf` | Fraunces | The Fraunces Project Authors | SIL Open Font License 1.1 ([text](Fraunces-OFL.txt)) | The human voice, titles |
| `Inter.ttf` | Inter | The Inter Project Authors (Rasmus Andersson) | SIL Open Font License 1.1 ([text](Inter-OFL.txt)) | Interface |
| `JetBrainsMono.ttf` | JetBrains Mono | The JetBrains Mono Project Authors | SIL Open Font License 1.1 ([text](JetBrainsMono-OFL.txt)) | The AI voice, code |
| `Minecraftia.ttf` | Minecraftia 2.0 | Andrew Tyler, 2014 | Creative Commons Attribution-ShareAlike 3.0 | The character's voice (as in 2023) |
| `EarlyGameBoy.ttf` | Early GameBoy | LDEJRuff, 2012 (FontStruct) | Creative Commons Attribution-ShareAlike 3.0 | The 2023 "Devam et" button |
| `04b.ttf` | 04b | Yuji Oshimoto, 2000 ([04.jp.org](http://www.04.jp.org)) | Freeware, as distributed by the author | The 2023 title |

Minecraftia, Early GameBoy and 04b are the typefaces the 2023 original used; they are kept so that
the 2023 parts look exactly as they did.

The fonts are not covered by the project's MIT licence. Each remains under its own terms.
